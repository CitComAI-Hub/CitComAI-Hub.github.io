*[NGSI-LD]: the ETSI standard API to publish and query context information (entities and their properties) as linked data
*[NGSI-v2]: the earlier FIWARE API for context information, which NGSI-LD replaces
*[JSON-LD]: JSON for Linked Data: JSON in which every term points to its definition, so that different systems read it the same way
*[ETSI]: European Telecommunications Standards Institute, the body that standardises NGSI-LD
*[EDC]: Eclipse Dataspace Components: an open-source framework to build data space connectors
*[DSP]: Dataspace Protocol: the protocol connectors use to publish catalogues, negotiate contracts and transfer data
*[EDR]: Endpoint Data Reference: the address and token that an EDC connector hands out to fetch the data of an agreement
*[DCAT]: Data Catalog Vocabulary: the W3C vocabulary to describe datasets in catalogues
*[ODRL]: Open Digital Rights Language: the W3C language to write the usage policies of an offer
*[OPA]: Open Policy Agent: the policy engine that allows or denies each request to a provider's connector
*[DID]: Decentralised Identifier: an identifier that an organisation controls itself and that resolves to its public keys
*[LEAR]: Legal Entity Appointed Representative: the person who acts for an organisation in the data space and signs for it
*[EUDI]: European Digital Identity: the EU framework for digital identity wallets under eIDAS 2.0
*[SD-JWT]: Selective Disclosure JSON Web Token: a credential format that lets the holder show only some of its claims
*[OID4VCI]: OpenID for Verifiable Credential Issuance: the protocol a wallet uses to receive a credential
*[OID4VP]: OpenID for Verifiable Presentations: the protocol a wallet uses to present a credential
*[BAE]: Business API Ecosystem: the FIWARE marketplace frontend for the TM Forum APIs, on which the CitCom marketplace is built
*[TRL]: Technology Readiness Level: a 1 to 9 scale of how mature a technology is
